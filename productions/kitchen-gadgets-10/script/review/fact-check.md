## 1. Rubbermaid Brilliance (#2): the four claims you asked about

Our product: **Rubbermaid Brilliance plastic, set of 3 containers / 6 pieces, ASIN B01JCNEJSO, model 2025903** (model
number from Amazon Singapore's title for the same ASIN).

| Claim (proposal wording) | Finding | Verdict |
|---|---|---|
| America's Test Kitchen tested and recommended this product | ATK's plastic-container winner is the **Rubbermaid Brilliance 10-piece set** (model **1976520**; 1×9.6-cup, 2×3.2-cup, 2×1.3-cup). ATK also tested individual Brilliance containers in several sizes. I found **no ATK page that names our 3-container set, model 2025903 or ASIN B01JCNEJSO**. The source originally saved in our research was ATK's **glass** container review, which was the wrong page. | ⛔ **Removed** from the script and Short 2. Not replaced with the 10-piece result. |
| Cracked lids / broken latches apply to this plastic product | The reports found are for **other** Brilliance products: the glass 6-pack (Canadian Tire), a 12-piece lunch kit and a 44-piece set (Walmart), and the 10-piece set (Home Depot). None is for the 3-container set. | ⛔ **Removed** as a claim about this product. Short 2 only tells viewers to *look for* such complaints when they read reviews. That is advice, not a claim. |
| Lids are not sold separately for this product | Only a third-party FAQ site and individual customer comments. There is no Rubbermaid statement for this set. | ⛔ **Removed** |
| Tomato sauce stains the lids/latches | The only source was a low-reliability blog. Rubbermaid markets Brilliance as stain-resistant, and customer reports conflict. | ⛔ **Removed** (already removed in the proposal) |

**What the revised script says instead** (all attributed to Rubbermaid): sold as leak-proof, airtight lids that latch
down, clear containers. Then the limitation, said plainly: *"We couldn't find an independent test of this exact
three-container set, so for now, leak-proof is Rubbermaid's promise, not something we could confirm."*

Other findings:
- The Prudent Reviews leak test (shaken or submerged) does not show which Brilliance set was used, so it was **removed**.
- The "latches take two hands" con came from the same low-reliability blog, so it was **removed**.
- Retailer listings disagree on what the "6-piece" set contains (2×1.3 + 1×9.6 cup vs 2×1.3 + 1×3.2 cup) and use
  different model numbers (1976519, 2180393). **Confirm the contents on the live Amazon page.**
- The AI shot that showed a container held upside down without leaking was **replaced** with a neutral one (packing
  a container into a lunch bag). The old shot would have shown a result we can't confirm.

**Your decision.** With these changes, #2 rests almost entirely on Rubbermaid's own claims. You have two options:
- **A (current revised script):** keep the 3-container set and keep the honest limitation in the script. Consider
  moving it lower in the ranking, because its evidence is now the weakest of the ten.
- **B:** switch #2 to the set ATK actually tested: Brilliance 10-piece, model 1976520. Amazon URL from search:
  <https://www.amazon.com/Rubbermaid-Brilliance-Container-10-Piece-1976520/dp/B01JCNEIC6>, not verified, so the
  contents and availability need checking. The ATK claim could then go back in, worded for that exact set.
